`josh/cleartext-handoff-20261019` includes the current `models/` implementation from `0a17b49`, plus the original experiment history from local branch `archive/experiments` at `05ad6e7`. This handoff adds saved settings and aggregate experiment results that were still excluded by the `runs/` and `outputs/` ignore rules. No runtime code or model defaults changed for this handoff.

The evidence is in [../evidence/handoff-20261019/](../evidence/handoff-20261019/). It contains historical results, not new evaluation runs. The artifact inventory is a receipt, not a download location. A fresh checkout needs the rebuilding steps in [../README.md](../README.md) before model inference will work.
