How we simplify a sentence without an LLM, step by step

Each step adds one block. Every block is its own small model or rule, trained on existing public data. At the end, the blocks vote together.

8

We turn the blocks into an ensemble

Word difficultySentence difficultyCandidatesSafety checksContextPhrases & structureMeaningEnsemble

Instead of each block saying yes or no, each gives a probability, and a small model learns how much to trust each one.

Meaning
SemCor + dictionary definitions. SemCor counts less when it has few examples ("alleviate" had one).
Fit
9 signals (meaning, context checker, vectors, grammar links, word pairs) combined by logistic regression on SWORDS.
Decision
Edit only if fit × how much simpler > (1 − fit) × cost of a wrong meaning.
87correct replacements (was 52), 48% of edits right.

The medication alleviates → relieves pain. Fixed

Until now every threshold was tuned on SWORDS, which asks "does this word fit?", not "is this a good simpler word?". We found a dataset that asks exactly that.

Data

Model
Logistic regression on top of every earlier signal, plus how common and how short each option is, and how it compares with the other options.
